# terms.airat.top

Public Terms of Use for AiratTop websites and services.

- Live site: https://terms.airat.top
- Privacy Policy: https://privacy.airat.top
- Status page: https://status.airat.top

## Structure

- `public_html/index.html` — page content and metadata.
- `public_html/styles.css` — layout and responsive styles.
- `wrangler.jsonc` — Cloudflare Workers static asset configuration.

## Deployment

The site has no build step. Deploy the contents of `public_html` to Cloudflare Workers with:

```bash
npx wrangler deploy
```
